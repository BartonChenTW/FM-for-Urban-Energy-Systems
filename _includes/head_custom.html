{%- comment -%} Open external links in a new tab, leaving internal navigation alone. Why a script rather than editing every link: the book's citations are Markdown footnotes written as [Title](https://doi.org/...), and Markdown has no syntax for target="_blank". Adding raw to each of the ~90 external links would make the source far less readable and be easy to forget on new citations. This handles every external link automatically, including ones added later. Internal links (chapter pages, anchors, the glossary) deliberately stay in the same tab -- opening a new tab for each step of normal navigation through the book would litter the reader's tab bar. rel="noopener noreferrer" is set alongside target="_blank": without noopener, the opened page gets a reference to this one via window.opener and can navigate it elsewhere (the "tabnabbing" issue). Modern browsers imply noopener for target="_blank", but older ones do not, and it costs nothing to be explicit. {%- endcomment -%}
