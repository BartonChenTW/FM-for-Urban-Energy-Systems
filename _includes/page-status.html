{% comment %} Renders a small status / last-reviewed badge from page front matter. Usage: add `{% include page-status.html %}` right after the page's first H1, on any page that sets `status` and/or `last_reviewed` in its front matter. Both fields are optional — the include renders nothing if neither is set, so it's safe to add everywhere.
